# Third-party reference

The Aternos monitoring behavior in this project was implemented independently in JavaScript using the public behavior and configuration documented by **Ayfri/aternos-watcher**.

Reference repository:
https://github.com/Ayfri/aternos-watcher

The reference project is published under GPL-3.0. This repository does not copy its source files; it reimplements the documented watcher behavior for the existing Discord bot architecture.
